# Calendar provider artwork

- [Google Calendar](https://github.com/edent/SuperTinyIcons/blob/master/images/svg/google_calendar.svg) and [Outlook](https://github.com/edent/SuperTinyIcons/blob/master/images/svg/outlook.svg): SuperTinyIcons, Terence Eden and contributors. MIT license included in LICENSE-SuperTinyIcons.txt.
- [Apple Calendar (iOS)](https://commons.wikimedia.org/wiki/File:Apple_Calendar_(iOS).svg): Apple Inc., vector artwork hosted on Wikimedia Commons. The source identifies this as public-domain simple artwork. Illustrator metadata, document type declarations and unused XML namespaces were removed; the artwork was retained.

These assets identify supported calendar-file providers. Their trademarks belong to their respective owners. Files are served locally; viewing the icons sends no request to those providers.
